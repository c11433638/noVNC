# 文件传输

刷新 noVNC 页面后，点击工具栏中的文件夹图标（剪贴板旁边）。桌面和手机浏览器均可使用，HTTP 和 HTTPS 共用同一接口。

- **上传**：点击“上传文件”，可以多选；文件保存到当前显示的远端文件夹。
- **下载**：将远端文件放进 `/home/ubuntu/Downloads/noVNC`，点击面板中的“刷新”，然后点击文件旁的“下载”。也可以进入该文件夹下的子文件夹。
- 远端桌面已有 **“noVNC 文件传输”** 文件夹快捷入口。
- **同名文件**：自动另存为 `文件名 (1).扩展名` 等名称，保留原文件。
- **取消**：取消当前上传并清理未完成文件；本批次已经完成的文件会保留。
- 单文件上传上限为 **10 GB（10 GiB）**。上传使用 **4 MB（4 MiB）** 的分块请求，以适应 Cloudflare Tunnel 的请求大小限制。
- 分块请求短暂失败时会检查远端已接收的字节位置并重试，避免重复写入。
- 上传时请保留页面打开。中断后重新选择文件上传；当前版本不支持断点续传或文件夹整体上传。

## 访问验证与文件范围

文件接口使用现有的 **VNC 完整访问密码** 验证。通常会自动使用本次连接输入的密码；否则面板会提示输入。密码不会写入浏览器存储。单独验证文件访问后使用 8 小时有效的 HttpOnly 会话 cookie，HTTPS 下设置 Secure。会话在网关重启后仍有效；VNC 密码文件变化会使会话失效。

桌面连接输入密码时，默认勾选 **“记住此浏览器 7 天”**。连接成功后，同一浏览器访问同一网址，在 7 天内刷新、关闭再打开页面或重连都不需要再次输入密码。文件面板也可使用这个登录状态。网关仅向浏览器返回当前 VNC 验证挑战的响应，不返回密码；浏览器保存的是有期限的 HttpOnly cookie。未勾选时只保留本次页面连接的密码。

设置面板中的 **“忘记浏览器登录”** 会撤销该浏览器会话；下一次桌面连接需要输入密码。更换浏览器、清除 cookie、会话过期或修改 VNC 密码后也需要重新登录。首次启用此功能需要刷新页面并登录一次。

只允许传输文件夹内的普通文件和子文件夹；隐藏文件、符号链接以及目录外路径不可访问。未完成上传位于传输文件夹中的隐藏目录 `.novnc-uploads`，不会出现在文件列表中。超过 24 小时的未完成上传会在后续上传时清理。

## 网关启动

`vnc-control.sh start` 使用 `utils/novnc_gateway.py` 启动 WebSocket、静态网页与文件接口。Python 3 需要系统现有的 `cryptography` 和仓库内的 `websockify`。

只重启网页网关、保留 VNC 桌面及其应用：

```sh
./vnc-control.sh web-restart
```

默认仍使用端口 `6990`，代理 `127.0.0.1:5901`，不需要改 Cloudflare Tunnel。可通过环境变量指定传输目录和密码文件：

```sh
NOVNC_FILES_DIR=/path/to/transfer VNC_PASSWORD_FILE=/path/to/vnc/passwd ./vnc-control.sh web-start
```

`web-stop` 只停止网页网关。原有 `stop` 和 `restart` 会停止 VNC 桌面，应按原来的用途使用。

验证文件接口：

```sh
python3 tests/test_file_transfer.py -v
python3 tests/test_browser_session.py -v
```
